# QS-007-온라인-의사결정-오버헤드

## 개요

### Quality Scenario ID
QS-007

### 제목
온라인 의사결정 오버헤드

### 설명
스케줄링·배치·분배·이동 결정(UC-001/004/005/008) 산출에 소요되는 런타임 오버헤드. 시스템 제약상 추론 지연(특히 TTFT)을 상쇄하지 않아야 한다.

### 품질 속성
성능 (의사결정 오버헤드)

## 환경

### 시스템 상태
MCR Runtime이 추론 경로 내에서 온라인으로 배치/분배 결정을 산출하며 가동 중이다.

### 초기 조건
- 성능 Cost 모델·정책·시스템 상태가 이용 가능하다.
- 결정 대상 요청이 주어진다.

### 부하 조건
다수 요청이 동시에 결정을 요구하는 운영 부하.

### 관련 컴포넌트
- InferenceScheduler
- KVCachePlacementPlanner
- ComputeDispatchPlanner
- KVCacheMigrator
- SystemStateStore

## 동작

추론 요청 처리 경로에서 시스템이 시스템 상태·Cost 모델·정책을 참조하여 배치/분배/이동 결정을 산출한다. 결정 산출 시작부터 완료까지의 시간 및 추론 경로에 추가되는 지연을 측정한다.

## 측정

- 측정 항목: 결정 산출 오버헤드 (ms)
- 측정 공식:

```
의사결정 오버헤드 = [결정 산출 완료 시각] - [결정 산출 시작 시각]
(추론 경로 추가 지연 = 결정 포함 경로 지연 - 결정 제외 경로 지연)
```

## 관련 문서

- UC-001 (비용 인지 메모리 중심 추론 스케줄링)
- UC-004 (KV Cache 계층 배치 결정)
- UC-008 (연산 자원 분배 결정)
- 시스템 제약: 온라인 의사결정 오버헤드 (system.md)
