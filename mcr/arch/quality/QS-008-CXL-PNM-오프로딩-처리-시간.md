# QS-008-CXL-PNM-오프로딩-처리-시간

## 개요

### Quality Scenario ID
QS-008

### 제목
CXL-PNM 오프로딩 처리 시간

### 설명
Attention 등 연산을 CXL-PNM으로 오프로딩(UC-006)했을 때의 연산 처리 시간.

### 품질 속성
성능 (처리량/지연)

## 환경

### 시스템 상태
CXL-PNM 디바이스가 Enable되어 드라이버/인터페이스로 접근 가능하며, MCR Runtime이 오프로딩을 수행한다.

### 초기 조건
- 오프로딩 대상 연산과 입력 데이터(또는 참조)가 준비되어 있다.
- 해당 연산이 CXL-PNM에서 지원되는 연산이다.

### 부하 조건
대상 연산이 반복적으로 오프로딩되는 워크로드.

### 관련 컴포넌트
- ComputeOffloadExecutor
- CXLPNMInterface

## 동작

서빙 프레임워크가 연산 오프로딩을 요청하면, 시스템은 CXL-PNM 디바이스에 연산 실행을 요청하고 결과를 수신하여 반환한다. 오프로딩 요청부터 결과 반환까지의 시간을 측정한다.

## 측정

- 측정 항목: CXL-PNM 오프로딩 처리 시간 (ms)
- 측정 공식:

```
오프로딩 처리 시간 = [오프로딩 결과 반환 시각] - [오프로딩 요청 시각]
```

## 관련 문서

- UC-006 (CXL-PNM 연산 오프로딩)
- 컴포넌트: ComputeOffloadExecutor, CXLPNMInterface
