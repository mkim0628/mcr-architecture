# QS-011-최적화-정책-교체-비용

## 개요

### Quality Scenario ID
QS-011

### 제목
최적화 정책 교체 비용

### 설명
스케줄링·분류/이동·오프로딩 정책(UC-011)을 교체·추가할 때의 변경 비용.

### 품질 속성
변경 용이성

## 환경

### 시스템 상태
MCR Runtime이 특정 최적화 정책 집합으로 운영되고 있으며, 정책이 PolicyStore에 관리된다.

### 초기 조건
- 교체 대상 정책(예: 스케줄링 정책)이 식별되어 있다.
- 정책은 결정 로직(InferenceScheduler 등)이 참조한다.

### 부하 조건
해당 없음 (개발/변경 활동).

### 관련 컴포넌트
- PolicyManager
- PolicyStore
- InferenceScheduler
- KVCacheClassifier
- ComputeDispatchPlanner

## 동작

운영자가 새로운 최적화 정책을 구성·교체한다. 정책 변경에 따라 수정해야 하는 컴포넌트/코드 범위를 식별하고, 결정 로직이 변경 없이 새 정책을 참조하는지 확인한다.

## 측정

- 측정 항목: 정책 교체 변경 비용
- 측정 공식:

```
변경 비용 = 정책 1건 교체 시 [영향받는 모듈 수] 및 [변경 코드 규모(LOC)]
```

## 관련 문서

- UC-011 (최적화 정책 구성 및 튜닝)
- 컴포넌트: PolicyManager, PolicyStore
