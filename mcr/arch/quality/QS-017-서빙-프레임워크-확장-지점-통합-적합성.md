# QS-017-서빙-프레임워크-확장-지점-통합-적합성

## 개요

### Quality Scenario ID
QS-017

### 제목
서빙 프레임워크 확장 지점 통합 적합성

### 설명
기존 서빙 프레임워크가 제공하는 확장 지점(스케줄러 훅, KV 캐시 관리 API) 범위 내에서 통합되는 적합성. 본체 수정을 최소화해야 한다.

### 품질 속성
상호 운용성

## 환경

### 시스템 상태
MCR Runtime이 ServingGatewayAPI를 통해 대상 서빙 프레임워크의 확장 지점에 연동되어 있다.

### 초기 조건
- 대상 서빙 프레임워크의 확장 지점(훅·API) 목록이 주어진다.
- 통합에 필요한 기능 요구가 식별되어 있다.

### 부하 조건
해당 없음 (통합/연동 적합성 평가).

### 관련 컴포넌트
- ServingGatewayAPI

## 동작

MCR Runtime을 대상 서빙 프레임워크에 통합한다. 통합을 위해 표준 확장 지점으로 충족되는 기능과, 프레임워크 본체 수정이 필요한 기능을 구분하여 측정한다.

## 측정

- 측정 항목: 통합 적합성 (본체 수정 최소화 정도)
- 측정 공식:

```
통합 적합성 = [표준 확장 지점으로 충족된 통합 요구 수] / [전체 통합 요구 수] × 100
(보조: 서빙 F/W 본체에 가해진 수정 규모(LOC))
```

## 관련 문서

- QS-014 (신규 서빙 프레임워크 통합 비용)
- 컴포넌트: ServingGatewayAPI
