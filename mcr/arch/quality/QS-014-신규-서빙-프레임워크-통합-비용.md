# QS-014-신규-서빙-프레임워크-통합-비용

## 개요

### Quality Scenario ID
QS-014

### 제목
신규 서빙 프레임워크 통합 비용

### 설명
통합 대상 LLM 서빙 프레임워크를 변경(예: vLLM↔SGLang)하거나 신규 통합할 때의 비용.

### 품질 속성
변경 용이성

## 환경

### 시스템 상태
MCR Runtime이 특정 서빙 프레임워크와 ServingGatewayAPI를 통해 통합되어 운영되고 있다.

### 초기 조건
- 신규 통합 대상 서빙 프레임워크의 확장 지점(스케줄러 훅, KV 캐시 관리 API) 사양이 주어진다.
- 통합은 ServingGatewayAPI를 통해 이루어진다.

### 부하 조건
해당 없음 (개발/변경 활동).

### 관련 컴포넌트
- ServingGatewayAPI

## 동작

신규 서빙 프레임워크를 통합하거나 기존 통합을 다른 프레임워크로 교체한다. ServingGatewayAPI 구현 및 결정 로직에 가해지는 변경 범위를 식별하여 측정한다.

## 측정

- 측정 항목: 서빙 프레임워크 통합·교체 비용
- 측정 공식:

```
변경 비용 = 서빙 F/W 1종 통합/교체 시 [영향받는 모듈 수] 및 [변경 코드 규모(LOC)]
```

## 관련 문서

- 시스템 제약: 기존 서빙 프레임워크 통합 제약 (system.md)
- 컴포넌트: ServingGatewayAPI
