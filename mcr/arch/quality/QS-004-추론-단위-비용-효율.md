# QS-004-추론-단위-비용-효율

## 개요

### Quality Scenario ID
QS-004

### 제목
추론 단위 비용 효율

### 설명
동일 처리량을 달성하는 데 소요되는 GPU·메모리 자원 비용. 핵심 비즈니스 KPI(추론 TCO 절감)와 직결된다.

### 품질 속성
성능 (비용 효율)

## 환경

### 시스템 상태
MCR Runtime이 서빙 프레임워크와 통합되어 정상 가동 중이며, 자원별 비용 특성이 성능 Cost 모델에 반영되어 있다.

### 초기 조건
- 고정된 워크로드와 자원 단가(GPU·메모리 계층·디바이스)가 주어진다.
- 성능 Cost 모델이 구성되어 있다.

### 부하 조건
대표 워크로드를 일정 처리량으로 처리하는 운영 부하.

### 관련 컴포넌트
- InferenceScheduler
- ComputeDispatchPlanner
- CostModelStore
- KVCachePlacementPlanner

## 동작

서빙 프레임워크의 요청을 처리하는 동안, 시스템은 비용 인지 스케줄링과 연산 분배를 수행한다. 처리에 소요된 GPU·메모리 자원량에 자원 단가를 곱하여 비용을 산출하고, 처리량으로 정규화한다.

## 측정

- 측정 항목: 단위 처리량당 자원 비용 (cost/token 또는 cost/request)
- 측정 공식:

```
단위 비용 = ([GPU 자원 비용] + [메모리 자원 비용]) / [처리량]
```

- UC-008 (연산 자원 분배 결정)
- UC-010 (성능 Cost 모델 관리)
- 컴포넌트: InferenceScheduler, CostModelStore
