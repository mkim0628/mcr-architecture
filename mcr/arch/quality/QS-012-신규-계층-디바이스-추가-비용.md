# QS-012-신규-계층-디바이스-추가-비용

## 개요

### Quality Scenario ID
QS-012

### 제목
신규 계층·디바이스 추가 비용

### 설명
신규 메모리 계층 또는 Computable-Memory 디바이스(차세대 CXL-PNM/PIM-SSD)를 추가할 때의 변경 비용.

### 품질 속성
변경 용이성

## 환경

### 시스템 상태
MCR Runtime이 현재의 메모리 계층/디바이스 집합을 대상으로 운영되고 있다.

### 초기 조건
- 추가 대상 메모리 계층/디바이스의 인터페이스 사양이 주어진다.
- 기존 디바이스는 MemoryTierInterface/CXLPNMInterface/PIMSSDInterface로 추상화되어 있다.

### 부하 조건
해당 없음 (개발/변경 활동).

### 관련 컴포넌트
- MemoryTierInterface
- CXLPNMInterface
- PIMSSDInterface
- CostModelStore
- ComputeDispatchPlanner

## 동작

신규 메모리 계층 또는 디바이스를 시스템에 추가한다. 추가에 필요한 인터페이스 구현, Cost 모델 특성 등록, 결정 로직 영향을 식별하여 변경 범위를 측정한다.

## 측정

- 측정 항목: 신규 계층/디바이스 추가 비용
- 측정 공식:

```
변경 비용 = 디바이스/계층 1종 추가 시 [영향받는 모듈 수] 및 [변경 코드 규모(LOC)]
```

## 관련 문서

- UC-006 (CXL-PNM 연산 오프로딩), UC-007 (PIM-SSD Retrieving 가속 오프로딩)
- UC-010 (성능 Cost 모델 관리)
- 컴포넌트: MemoryTierInterface, CXLPNMInterface, PIMSSDInterface
