# QS-020-오프로딩-실패-처리-신뢰성

## 개요

### Quality Scenario ID
QS-020

### 제목
오프로딩 실패 처리 신뢰성

### 설명
CXL-PNM/PIM-SSD 오프로딩(UC-006/007) 실패 시 정상 결과 반환 또는 복구의 신뢰성.

### 품질 속성
신뢰성

## 환경

### 시스템 상태
MCR Runtime이 CXL-PNM/PIM-SSD로 연산·검색을 오프로딩하는 중, 디바이스 실패가 주입될 수 있는 상태.

### 초기 조건
- 오프로딩 대상 연산/검색 요청이 주어진다.
- 디바이스 실패(미지원·실행 오류·데이터셋 부재 등)를 주입할 수 있다.

### 부하 조건
오프로딩 요청 중 일정 비율로 실패가 주입되는 워크로드.

### 관련 컴포넌트
- ComputeOffloadExecutor
- RetrievalOffloadExecutor
- CXLPNMInterface
- PIMSSDInterface

## 동작

오프로딩 요청에 디바이스 실패를 주입한다. 시스템이 실패를 감지하여 올바른 오류 정보를 반환하거나 정상 처리 경로로 복구하는지 확인하고, 성공적으로 처리된 비율을 집계한다.

## 측정

- 측정 항목: 오프로딩 실패 처리 성공률 (%)
- 측정 공식:

```
실패 처리 성공률 = [올바른 오류 반환 또는 복구에 성공한 횟수] / [전체 실패 주입 횟수] × 100
```

## 관련 문서

- UC-006 (CXL-PNM 연산 오프로딩), UC-007 (PIM-SSD Retrieving 가속 오프로딩)
- 컴포넌트: ComputeOffloadExecutor, RetrievalOffloadExecutor
