# QS-015-메모리-계층-확장-대응

## 개요

### Quality Scenario ID
QS-015

### 제목
메모리 계층 확장 대응

### 설명
메모리 계층 수/용량이 증가할 때 스케줄링·배치 결정의 성능 유지 정도.

### 품질 속성
확장성

## 환경

### 시스템 상태
MCR Runtime이 다수의 메모리 계층을 대상으로 배치·스케줄링 결정을 수행한다.

### 초기 조건
- 메모리 계층 수/용량이 단계적으로 증가하는 구성이 주어진다.
- 성능 Cost 모델과 시스템 상태가 이용 가능하다.

### 부하 조건
계층 수 증가에 따른 결정 대상 후보 증가.

### 관련 컴포넌트
- InferenceScheduler
- KVCachePlacementPlanner
- SystemStateStore
- ResourceStateMonitor

## 동작

메모리 계층 수/용량을 증가시키면서 동일 워크로드에 대해 배치/스케줄링 결정을 수행한다. 계층 수 증가에 따른 결정 산출 시간과 처리량 변화를 측정한다.

## 측정

- 측정 항목: 계층 수 증가에 따른 결정 시간/처리량 변화
- 측정 공식:

```
확장 대응성 = 계층 수 N 변화에 대한 [결정 산출 시간] 및 [처리량]의 변화 추이
```

## 관련 문서

- UC-001 (비용 인지 메모리 중심 추론 스케줄링)
- UC-004 (KV Cache 계층 배치 결정)
- 컴포넌트: KVCachePlacementPlanner, SystemStateStore
