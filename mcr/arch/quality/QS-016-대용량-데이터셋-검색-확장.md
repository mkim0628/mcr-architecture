# QS-016-대용량-데이터셋-검색-확장

## 개요

### Quality Scenario ID
QS-016

### 제목
대용량 데이터셋 검색 확장

### 설명
PIM-SSD 검색 대상 데이터셋이 증가할 때 검색 처리량의 확장성.

### 품질 속성
확장성

## 환경

### 시스템 상태
PIM-SSD 디바이스가 Enable되어 있고, 검색 대상 데이터셋이 단계적으로 증가하는 구성.

### 초기 조건
- 데이터셋 크기를 단계적으로 증가시키며 검색 질의를 유입한다.
- 검색 연산이 PIM-SSD에서 지원된다.

### 부하 조건
데이터셋 크기 증가에 따른 검색 부하 증가.

### 관련 컴포넌트
- RetrievalOffloadExecutor
- PIMSSDInterface

## 동작

검색 대상 데이터셋 크기를 단계적으로 증가시키면서 동일 패턴의 검색 질의를 처리한다. 데이터셋 크기 증가에 따른 검색 처리량/지연의 변화를 측정한다.

## 측정

- 측정 항목: 데이터셋 크기 증가에 따른 검색 처리량/지연 변화
- 측정 공식:

```
검색 확장성 = 데이터셋 크기 S 변화에 대한 [검색 처리량(queries/s)] 및 [검색 지연]의 변화 추이
```

## 관련 문서

- UC-007 (PIM-SSD Retrieving 가속 오프로딩)
- QS-009 (PIM-SSD 검색 지연)
- 컴포넌트: RetrievalOffloadExecutor, PIMSSDInterface
