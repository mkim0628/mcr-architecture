# QS-006-KV-메모리-풋프린트-절감

## 개요

### Quality Scenario ID
QS-006

### 제목
KV 메모리 풋프린트 절감

### 설명
KV 캐시 압축(UC-003) 적용 시 메모리 풋프린트가 절감되는 정도.

### 품질 속성
성능 (자원 효율)

## 환경

### 시스템 상태
MCR Runtime이 가동 중이며, KV 캐시 압축 방식이 구성되어 있다.

### 초기 조건
- 압축 대상 KV 캐시가 메모리 계층에 존재한다.
- KVCacheRegistry에 압축 상태가 관리된다.

### 부하 조건
대용량 KV 캐시를 보유하는 긴 컨텍스트 워크로드.

### 관련 컴포넌트
- KVCacheCompressor
- KVCacheRegistry
- MemoryTierInterface

## 동작

서빙 프레임워크가 KV 캐시 압축을 요청하면, 시스템은 압축 방식을 적용하여 압축본을 메모리 계층에 저장하고 압축 상태를 기록한다. 압축 전후의 메모리 사용량을 측정한다.

## 측정

- 측정 항목: KV 메모리 풋프린트 절감률 (압축률, %)
- 측정 공식:

```
절감률 = ([압축 전 메모리 사용량] - [압축 후 메모리 사용량]) / [압축 전 메모리 사용량] × 100
```

## 관련 문서

- UC-003 (KV 캐시 압축)
- 컴포넌트: KVCacheCompressor, KVCacheRegistry
