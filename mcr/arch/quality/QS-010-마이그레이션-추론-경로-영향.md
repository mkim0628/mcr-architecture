# QS-010-마이그레이션-추론-경로-영향

## 개요

### Quality Scenario ID
QS-010

### 제목
마이그레이션 추론 경로 영향

### 설명
KV Cache 계층 간 이동(UC-005)이 진행 중인 추론 경로(TTFT·처리량)에 미치는 지연 영향.

### 품질 속성
성능 (지연)

## 환경

### 시스템 상태
MCR Runtime이 가동 중이며, 분류 결과에 따라 KV Cache의 계층 간 마이그레이션이 수행되는 상황.

### 초기 조건
- 마이그레이션 대상 KV Cache와 분류 정책이 구성되어 있다.
- 동시에 추론 요청이 처리되고 있다.

### 부하 조건
마이그레이션 활성 구간과 비활성 구간이 공존하는 운영 부하.

### 관련 컴포넌트
- KVCacheClassifier
- KVCacheMigrator
- MemoryTierInterface
- KVCacheRegistry

## 동작

시스템이 KV Cache를 분류하고 계층 간 이동을 수행하는 동안에도 추론 요청이 처리된다. 마이그레이션이 활성인 구간과 비활성인 구간에서 추론 경로의 TTFT/처리량을 각각 측정하여 그 차이를 산출한다.

## 측정

- 측정 항목: 마이그레이션으로 인한 추론 경로 지연 영향 (ms 또는 %)
- 측정 공식:

```
지연 영향 = [마이그레이션 활성 구간 TTFT] - [마이그레이션 비활성 구간 TTFT]
(처리량 영향 = (비활성 처리량 - 활성 처리량) / 비활성 처리량 × 100)
```

## 관련 문서

- UC-005 (KV Cache 분류 및 계층 간 이동)
- QS-001 (TTFT), QS-002 (추론 처리량)
- 컴포넌트: KVCacheMigrator, KVCacheClassifier
