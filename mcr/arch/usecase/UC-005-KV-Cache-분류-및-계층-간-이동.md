# UC-005-KV-Cache-분류-및-계층-간-이동

## 개요

### Use Case ID
UC-005

### 제목
KV Cache 분류 및 계층 간 이동

### 설명
데이터 성격에 따라 KV Cache를 분류(Classification)하고, 분류 정책에 따라 메모리 계층 간 이동(Migration)을 수행하여 계층별 효율을 확보한다.

## 액터

### Primary Actor
서빙 프레임워크 (시스템 액터)
- **역할**: KV Cache 접근/사용 컨텍스트를 전달하고 분류·이동 처리를 위임받는다.
- **설명**: MCR Runtime을 호출하는 상위 LLM 서빙 스택.

### Secondary Actor
이기종 메모리 계층
- **역할**: 분류 결과에 따른 이동의 원본/대상 계층을 제공한다.
- **설명**: PIM/PNM·DRAM·CXL·SSD로 구성된 메모리 계층.

## 사전조건

- 분류·이동 대상 KV Cache가 메모리 계층에 존재한다.
- 분류 정책이 구성되어 있다. (UC-011)
- 각 계층의 상태·용량 정보가 이용 가능하다. (UC-009)

## 사후조건

- KV Cache가 데이터 성격에 따라 분류된다.
- 분류 결과에 따라 필요한 계층 간 이동이 수행된다.
- 분류·이동 결과가 서빙 프레임워크에 반환된다.

## 주요 시나리오

1. 서빙 프레임워크가 시스템에게 KV Cache의 접근/사용 컨텍스트를 전달하며 분류·이동을 요청한다.
2. 시스템은 분류 정책을 기준으로 KV Cache의 데이터 성격(예: hot/cold)을 분류한다.
3. 시스템은 분류 결과와 현재 계층 배치를 비교하여 이동 필요 여부를 판단한다.
4. 시스템은 이동이 필요한 KV Cache의 대상 계층을 결정한다.
5. 시스템은 이기종 메모리 계층에 KV Cache 이동을 지시한다.
6. 시스템은 서빙 프레임워크에 분류·이동 결과를 반환한다.

## 대안 시나리오

### 3a. 이동이 필요하지 않은 경우
분류 결과가 현재 계층 배치와 일치하는 경우.

3a.1. 시스템은 이동을 수행하지 않는다.
3a.2. 시스템은 서빙 프레임워크에 현재 배치 유지 결과를 반환한다.

### 4a. 대상 계층의 용량이 부족한 경우
이동 대상 계층에 가용 용량이 부족한 경우.

4a.1. 시스템은 차순위 적합 계층으로 이동 대상을 재결정한다.
4a.2. 시스템은 주요 시나리오 5단계로 진행한다.

## 예외 시나리오

### E1. 분류 정책이 구성되지 않은 경우
참조할 분류 정책이 없는 경우.

E1.1. 시스템은 분류를 수행할 수 없음을 판단한다.
E1.2. 시스템은 서빙 프레임워크에 정책 미구성 오류를 반환한다.

### E2. 이동 중 원본 KV Cache가 무효화된 경우
이동 대상 KV Cache가 이동 도중 해제/무효화된 경우.

E2.1. 시스템은 해당 이동을 중단한다.
E2.2. 시스템은 서빙 프레임워크에 이동 중단 정보를 반환한다.

## 관련 Use Case

- UC-004 (KV Cache 계층 배치 결정): 초기 배치 이후의 재배치를 담당
- UC-011 (최적화 정책 구성·튜닝): 분류 정책을 제공
- UC-009 (워크로드·상태 모니터링): 분류/이동 판단의 입력 제공

## 비고

분류 기준과 이동 대상 결정은 기능적 요구사항이다. 이동이 추론 경로(TTFT)에 미치는 영향을 줄이는 내부 설계는 Phase 4·5에서 다룬다.
