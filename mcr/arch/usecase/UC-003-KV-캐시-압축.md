# UC-003-KV-캐시-압축

## 개요

### Use Case ID
UC-003

### 제목
KV 캐시 압축

### 설명
KV 캐시를 압축하여 메모리 풋프린트를 줄이고, 필요 시 복원하여 추론에 사용한다.

## 액터

### Primary Actor
서빙 프레임워크 (시스템 액터)
- **역할**: 압축/복원 대상 KV 캐시를 전달하고 결과를 위임받는다.
- **설명**: MCR Runtime을 호출하는 상위 LLM 서빙 스택.

### Secondary Actor
이기종 메모리 계층
- **역할**: 압축된 KV 캐시가 저장되는 대상이다.
- **설명**: PIM/PNM·DRAM·CXL·SSD로 구성된 메모리 계층.

## 사전조건

- 압축 또는 복원 대상 KV 캐시가 존재한다.
- 적용할 압축 방식이 구성되어 있다.

## 사후조건

- 대상 KV 캐시가 압축되어 저장되거나, 압축된 KV 캐시가 복원된다.
- 처리 결과가 서빙 프레임워크에 반환된다.

## 주요 시나리오

1. 서빙 프레임워크가 시스템에게 KV 캐시와 함께 압축(또는 복원)을 요청한다.
2. 시스템은 대상 KV 캐시에 압축 방식을 적용한다.
3. 시스템은 압축된 KV 캐시를 메모리 계층에 저장한다.
4. 시스템은 서빙 프레임워크에 압축 처리 결과를 반환한다.

## 대안 시나리오

### 1a. 복원을 요청하는 경우
압축된 KV 캐시의 복원을 요청한 경우.

1a.1. 시스템은 압축된 KV 캐시를 원본 형태로 복원한다.
1a.2. 시스템은 서빙 프레임워크에 복원된 KV 캐시를 반환한다.

## 예외 시나리오

### E1. 압축/복원 처리에 실패한 경우
대상 데이터가 손상되었거나 처리에 실패한 경우.

E1.1. 시스템은 처리 실패를 판단한다.
E1.2. 시스템은 서빙 프레임워크에 처리 실패 정보를 반환한다.

## 관련 Use Case

- UC-002 (Non-contiguous KV 캐시 재사용): 재사용 대상의 압축/복원과 연계
- UC-004 (KV Cache 계층 배치 결정): 압축 상태가 계층 배치에 영향

## 비고

압축률과 복원 정확성은 기능적 요구사항이다. 압축/복원 비용과 메모리 절감 간 트레이드오프 최적화는 Phase 4·5에서 다룬다.
