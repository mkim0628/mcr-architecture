# UC-002-Non-contiguous-KV-캐시-재사용

## 개요

### Use Case ID
UC-002

### 제목
Non-contiguous KV 캐시 재사용

### 설명
토큰 위치가 정확히 일치하지 않아도 재사용 가능한 KV 캐시 영역을 식별하여 재사용함으로써, 동일 내용에 대한 재연산을 줄인다.

## 액터

### Primary Actor
서빙 프레임워크 (시스템 액터)
- **역할**: 추론 요청과 KV 캐시 핸들을 전달하고 재사용 가능한 KV 캐시 결과를 위임받는다.
- **설명**: MCR Runtime을 호출하는 상위 LLM 서빙 스택.

### Secondary Actor
이기종 메모리 계층
- **역할**: 기존 KV 캐시가 저장된 대상이며, 재사용 대상 KV 영역을 제공한다.
- **설명**: PIM/PNM·DRAM·CXL·SSD로 구성된 메모리 계층.

## 사전조건

- 재사용 후보가 되는 기존 KV 캐시가 메모리 계층에 존재한다.
- 서빙 프레임워크가 현재 요청의 토큰 시퀀스/KV 캐시 핸들을 제공한다.

## 사후조건

- 재사용 가능한 비연속 KV 캐시 영역이 식별된다.
- 재사용 결과(재사용 영역 및 재연산 필요 영역)가 서빙 프레임워크에 반환된다.

## 주요 시나리오

1. 서빙 프레임워크가 시스템에게 현재 요청의 토큰 시퀀스와 KV 캐시 핸들을 전달하며 재사용 가능 여부를 요청한다.
2. 시스템은 기존 KV 캐시에서 토큰 위치가 일치하지 않아도 재사용 가능한 비연속 영역을 탐색한다.
3. 시스템은 식별된 재사용 영역의 유효성을 확인한다.
4. 시스템은 재사용 영역과 재연산이 필요한 영역을 구분한다.
5. 시스템은 서빙 프레임워크에 재사용 가능한 KV 캐시 영역과 재연산 필요 영역을 반환한다.

## 대안 시나리오

### 2a. 재사용 가능한 영역이 없는 경우
일치하거나 재사용 가능한 비연속 영역이 발견되지 않은 경우.

2a.1. 시스템은 재사용 영역이 없음을 판단한다.
2a.2. 시스템은 서빙 프레임워크에 전체 재연산이 필요함을 반환한다.

### 2b. 부분 영역만 재사용 가능한 경우
일부 비연속 영역만 재사용 가능한 경우.

2b.1. 시스템은 재사용 가능한 부분 영역만 선별한다.
2b.2. 시스템은 주요 시나리오 4단계로 진행한다.

## 예외 시나리오

### E1. KV 캐시 핸들이 유효하지 않은 경우
전달된 KV 캐시 핸들이 만료되었거나 잘못된 경우.

E1.1. 시스템은 핸들 무효 상태를 판단한다.
E1.2. 시스템은 서빙 프레임워크에 무효 핸들 오류를 반환한다.

### E2. 재사용 영역의 무결성 검증에 실패한 경우
식별된 재사용 영역이 손상되었거나 무결성 검증에 실패한 경우.

E2.1. 시스템은 해당 영역을 재사용 대상에서 제외한다.
E2.2. 시스템은 서빙 프레임워크에 해당 영역을 재연산 필요로 반환한다.

## 관련 Use Case

- UC-001 (비용 인지 추론 스케줄링): 재사용 결과가 스케줄링 결정의 입력
- UC-003 (KV 캐시 압축): 재사용 대상 KV 캐시의 압축/복원과 연계

## 비고

재사용 정확성(위치 불일치 재사용 시 결과 무결성)은 기능적 요구사항으로 검증한다. 재사용 탐색의 내부 자료구조·성능 최적화는 Phase 4·5에서 다룬다.
