# UC-008-연산-자원-분배-결정

## 개요

### Use Case ID
UC-008

### 제목
연산 자원 분배 결정

### 설명
성능 Cost 모델을 기반으로 GPU·CXL-PNM·PIM-SSD 간 연산을 분배하고, 가속 전략(Pipelining, Tiling, Data Placement)을 적용한다.

## 액터

### Primary Actor
서빙 프레임워크 (시스템 액터)
- **역할**: 처리할 연산과 컨텍스트를 전달하고 연산 분배 결정을 위임받는다.
- **설명**: MCR Runtime을 호출하는 상위 LLM 서빙 스택.

### Secondary Actor
연산 자원 (GPU / CXL-PNM / PIM-SSD)
- **역할**: 분배 결정에 따라 연산을 수행하는 대상 자원이며, 가용 상태를 제공한다.
- **설명**: GPU 가속기 및 Computable-Memory 디바이스.

## 사전조건

- 성능 Cost 모델이 구성되어 있다. (UC-010)
- 각 연산 자원(GPU·CXL-PNM·PIM-SSD)의 가용 상태가 이용 가능하다. (UC-009)
- 처리할 연산과 컨텍스트가 제공된다.

## 사후조건

- 각 연산의 수행 자원이 결정된다.
- 적용할 가속 전략이 결정된다.
- 연산 분배 결정이 서빙 프레임워크에 반환된다.

## 주요 시나리오

1. 서빙 프레임워크가 시스템에게 처리할 연산과 컨텍스트(연산 종류·데이터 위치 등)를 전달하며 분배 결정을 요청한다.
2. 시스템은 각 연산 자원의 가용 상태와 데이터 위치를 조회한다.
3. 시스템은 성능 Cost 모델을 기반으로 자원별 수행 비용을 평가한다.
4. 시스템은 비용이 최소가 되도록 각 연산의 수행 자원을 결정한다.
5. 시스템은 결정에 적합한 가속 전략(Pipelining·Tiling·Data Placement)을 선택한다.
6. 시스템은 서빙 프레임워크에 연산 분배 결정과 가속 전략을 반환한다.

## 대안 시나리오

### 4a. 특정 자원이 가용하지 않은 경우
선호 자원이 사용 불가하거나 과부하인 경우.

4a.1. 시스템은 가용한 자원으로 분배를 재평가한다.
4a.2. 시스템은 주요 시나리오 5단계로 진행한다.

### 5a. 적용 가능한 가속 전략이 복수인 경우
복수의 가속 전략이 적용 가능한 경우.

5a.1. 시스템은 Cost 모델 기준으로 가장 유리한 전략을 선택한다.
5a.2. 시스템은 주요 시나리오 6단계로 진행한다.

## 예외 시나리오

### E1. 성능 Cost 모델이 이용 불가한 경우
Cost 모델이 구성되지 않았거나 로드에 실패한 경우.

E1.1. 시스템은 분배 결정을 산출할 수 없음을 판단한다.
E1.2. 시스템은 서빙 프레임워크에 결정 불가 오류를 반환한다.

### E2. 모든 연산 자원이 가용하지 않은 경우
GPU·CXL-PNM·PIM-SSD가 모두 사용 불가한 경우.

E2.1. 시스템은 분배 불가 상태를 판단한다.
E2.2. 시스템은 서빙 프레임워크에 자원 부재 오류를 반환한다.

## 관련 Use Case
