# UC-007-PIM-SSD-Retrieving-가속-오프로딩

## 개요

### Use Case ID
UC-007

### 제목
PIM-SSD Retrieving 가속 오프로딩

### 설명
대용량 데이터 검색(Retrieving) 연산을 PIM-SSD로 In-Storage 오프로딩하여 검색 지연과 데이터 이동 비용을 최소화한다.

## 액터

### Primary Actor
서빙 프레임워크 (시스템 액터)
- **역할**: 검색 질의와 대상 데이터셋 참조를 전달하고 검색 결과를 위임받는다.
- **설명**: MCR Runtime을 호출하는 상위 LLM 서빙 스택.

### Secondary Actor
PIM-SSD 디바이스
- **역할**: In-Storage 검색 연산을 실행하고 결과를 반환한다.
- **설명**: 드라이버/인터페이스를 통해 접근하는 Computable-Memory 디바이스.

## 사전조건

- PIM-SSD 디바이스가 Enable되어 드라이버/인터페이스로 접근 가능하다.
- 검색 대상 데이터셋이 PIM-SSD에 존재한다.
- 검색 질의가 PIM-SSD에서 지원되는 검색 연산 형태이다.

## 사후조건

- 검색 연산이 PIM-SSD 내에서 실행된다.
- 검색 결과가 서빙 프레임워크에 반환된다.

## 주요 시나리오

1. 서빙 프레임워크가 시스템에게 검색 질의와 대상 데이터셋 참조를 전달하며 검색 가속을 요청한다.
2. 시스템은 해당 검색 연산이 PIM-SSD에서 지원되는지 확인한다.
3. 시스템은 PIM-SSD 디바이스에 In-Storage 검색 실행을 요청한다.
4. PIM-SSD 디바이스는 검색을 실행하고 결과를 시스템에 반환한다.
5. 시스템은 서빙 프레임워크에 검색 결과를 반환한다.

## 대안 시나리오

### 4a. 검색 결과가 다량인 경우
검색 결과 항목이 다수인 경우.

4a.1. 시스템은 요청 조건(상위 K 등)에 따라 결과를 선별한다.
4a.2. 시스템은 주요 시나리오 5단계로 진행한다.

## 예외 시나리오

### E1. 대상 데이터셋이 PIM-SSD에 존재하지 않는 경우
검색 대상이 디바이스에 적재되지 않은 경우.

E1.1. 시스템은 검색을 수행할 수 없음을 판단한다.
E1.2. 시스템은 서빙 프레임워크에 데이터셋 부재 오류를 반환한다.

### E2. PIM-SSD 검색 실행에 실패한 경우
디바이스 오류로 검색 실행에 실패한 경우.

E2.1. 시스템은 검색 오프로딩 실패를 판단한다.
E2.2. 시스템은 서빙 프레임워크에 검색 실패 정보를 반환한다.

## 관련 Use Case

- UC-008 (연산 자원 분배 결정): 검색 연산을 PIM-SSD에 오프로딩할지 결정
- UC-006 (CXL-PNM 연산 오프로딩): 동종의 디바이스 오프로딩 기능
