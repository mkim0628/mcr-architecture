# UC-006-CXL-PNM-연산-오프로딩

## 개요

### Use Case ID
UC-006

### 제목
CXL-PNM 연산 오프로딩

### 설명
Attention 등 LLM 연산을 CXL-PNM 디바이스로 오프로딩하여 GPU 연산 부하와 데이터 이동 비용을 줄인다.

## 액터

### Primary Actor
서빙 프레임워크 (시스템 액터)
- **역할**: 오프로딩 대상 연산과 입력 데이터 참조를 전달하고 오프로딩 실행 결과를 위임받는다.
- **설명**: MCR Runtime을 호출하는 상위 LLM 서빙 스택.

### Secondary Actor
CXL-PNM 디바이스
- **역할**: 오프로딩된 연산을 실행하고 결과를 반환한다.
- **설명**: 드라이버/인터페이스를 통해 접근하는 Computable-Memory 디바이스.

## 사전조건

- CXL-PNM 디바이스가 Enable되어 드라이버/인터페이스로 접근 가능하다.
- 오프로딩 대상 연산과 입력 데이터(또는 그 메모리 참조)가 준비되어 있다.
- 해당 연산이 CXL-PNM에서 지원되는 연산 종류이다.

## 사후조건

- 대상 연산이 CXL-PNM 디바이스에서 실행된다.
- 연산 결과가 서빙 프레임워크에 반환된다.

## 주요 시나리오

1. 서빙 프레임워크가 시스템에게 오프로딩 대상 연산(예: Attention)과 입력 데이터 참조를 전달하며 오프로딩을 요청한다.
2. 시스템은 해당 연산이 CXL-PNM에서 지원되는지 확인한다.
3. 시스템은 CXL-PNM 디바이스에 연산 실행을 요청한다.
4. CXL-PNM 디바이스는 연산을 실행하고 결과를 시스템에 반환한다.
5. 시스템은 서빙 프레임워크에 연산 결과를 반환한다.

## 대안 시나리오

### 1a. 연산의 일부만 오프로딩 대상인 경우
연산의 일부만 CXL-PNM으로 처리하는 경우.

1a.1. 시스템은 오프로딩 가능한 부분 연산만 CXL-PNM에 요청한다.
1a.2. 시스템은 나머지 부분의 결과와 통합하여 주요 시나리오 5단계로 진행한다.

## 예외 시나리오

### E1. CXL-PNM 디바이스가 지원하지 않는 연산인 경우
요청된 연산이 디바이스에서 지원되지 않는 경우.

E1.1. 시스템은 해당 연산을 오프로딩 대상에서 제외한다.
E1.2. 시스템은 서빙 프레임워크에 미지원 연산 정보를 반환한다.

### E2. CXL-PNM 디바이스 실행에 실패한 경우
디바이스 오류로 연산 실행에 실패한 경우.

E2.1. 시스템은 오프로딩 실패를 판단한다.
E2.2. 시스템은 서빙 프레임워크에 오프로딩 실패 정보를 반환한다.
